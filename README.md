# Website Intelligence APIs

## 10 Powerful Website Analysis APIs — One Engine

| # | API | Description |
|---|-----|-------------|
| 1 | Website → Markdown | Convert any web page to clean Markdown |
| 2 | Website Metadata | Extract meta tags, headings, images, links |
| 3 | Technology Detector | Detect CMS, frameworks, analytics, CDN |
| 4 | Contact Extractor | Extract emails, phones, social links, address |
| 5 | AI Website Summary | Structured + AI-powered summary |
| 6 | OpenGraph Extractor | OG tags, Twitter Cards, preview analysis |
| 7 | Robots.txt Parser | Parse crawl rules, sitemaps |
| 8 | Sitemap Parser | Parse XML sitemaps with URL analysis |
| 9 | SSL Checker | Certificate details, expiry, security grade |
| 10 | DNS Lookup | A, AAAA, MX, NS, CNAME, subdomains |

See rapidapi/ for OpenAPI spec and apify/ for Actor packaging.
